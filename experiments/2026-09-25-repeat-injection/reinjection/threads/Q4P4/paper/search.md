# Prior-work search for the Q4P4 result

Search date: 25 September 2026. The target was the specific result that a fixed-batch expected empirical CVaR value can pass a state-independent obedience-cycle test when the true conditional CVaR value fails it. Searches used the web index. I read the supplied Q and P manuscripts, the arXiv abstract pages listed below, and the original text or publisher page of the other cited works. The searches do not prove that no closer work exists.
