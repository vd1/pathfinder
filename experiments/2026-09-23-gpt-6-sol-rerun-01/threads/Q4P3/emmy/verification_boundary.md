# Verification boundary in adversarial review

## Source check

Q defines a verification order in which a type can withhold a certificate but cannot counterfeit one (Q.tex, lines 299–308). Its peer-discipline proposition instead requires distinct conditional distributions of co-player types, a known conditional-belief map, a quadratic score, utility cancellation, and off-path penalties (Q.tex, lines 1649–1709). Its nested cyclical monotonicity result concerns implementable single-agent policies with a reward schedule (Q.tex, lines 522–620). None applies directly to P's prompt-only reviewer and critic.

P's critic sees the reviewer's latest review and their prior exchange before replying (P.tex, lines 1083–1121). In the failed review case, the critic raises a real concern, receives an unsupported rebuttal, then agrees; the final review drops the bug (P.tex, lines 328–337). The revision asks the critic to distinguish code-backed disagreement from an epistemic concern and requires the reviewer to cite code to settle the latter (P.tex, lines 338–356 and 1122–1235). The reported review F1 rises from \(0.457\) to \(0.533\) on \(100\) PRs (P.tex, lines 281–312). This comparison bundles several prompt changes and does not isolate the evidence rule.

## Proposed question

When does requiring a code citation discipline review, and when does it prematurely settle a challenged flag whose decisive evidence is outside the visible diff? The direct rule in P concerns an *existing reviewer flag* challenged by the critic as \(\texttt{DISAGREE\_CONCERN}\): the reviewer must cite diff code to keep or drop it (P.tex, lines 342–356 and 1151–1173). The critic also names missed bugs, which the reviewer is instructed to incorporate under any verdict (P.tex, lines 1207–1214 and 1172–1175). Those new suggestions face a different path; final formatting can affect either kind of finding (P.tex, lines 315–326). Let \(V=1\) mean that a claim has a checkable witness in the supplied diff, and \(V=0\) mean that deciding it requires a specification, another repository file, execution, or a missing-behavior argument. A citation to a line verifies that the line exists; it does not itself verify the semantic claim. Thus a bare citation does not have Q's non-counterfeitable-certificate property.

The prediction is an interaction for *challenged existing flags*: P's evidence rule may reduce unsupported positives most strongly at \(V=1\), while reducing recall at \(V=0\) if the reviewer resolves a context-dependent concern using only a diff citation. Both signs require a causal test, and the second is not an observed P result. Any effect on newly suggested missed bugs is separate and may arise from their own prompt instructions or final formatting. P's repository repair case in which a speculative `read()` concern expands the patch beyond the issue scope illustrates that relevance to the task also needs verification (P.tex, lines 553–579). Q's weak-monitor section shows why broader monitor discretion can improve the monitor's objective while worsening the human's (Q.tex, lines 2181–2199); applying that result literally to P would require measured preferences and an enforceable instrument.

## Minimal formal boundary

Consider two states \(\theta\in\{0,1\}\) that produce the same visible diff and problem statement but differ in unobserved repository context. Suppose the protocol accepts only certificates that can be checked from those visible inputs, and no external test or audit is available. The available certificate set is identical in the two states. A decision rule based only on those inputs and certificates therefore has the same output distribution in both states. If the correct review decision differs by state, the rule cannot be correct in both. This is an information limit for a certificate-only protocol, not a claim that P has proven such a failure or that all real bugs need external context. Additional independent signals or an externally checked test can break the observational equivalence.

## Discriminating experiment

Replay the same PRs under randomized review protocols: P's original AR, its text-constrained AR, and an evidence rule that permits an explicit unresolved challenged flag with a requested test or repository-context check. Fix the model, diff, problem statement, token budget, and final review formatter. Blindly adjudicate candidate findings for correctness, task relevance, and witness location. Track challenged existing flags separately from newly suggested missed bugs, then measure precision and recall by witness class, dissent survival after a reviewer rebuttal, and the rate at which unresolved flags trigger a useful context check. A decisive pattern would be higher precision for diff-local challenged flags with the strict gate but lower recall for context-dependent challenged flags, recovered by the explicit unresolved state. If no interaction appears, the proposed boundary has little empirical support.

P supplies only two review failure case studies and aggregate F1, not witness-stratified data, so this remains a proposal. The real publication contribution would require the stratified result and a formal model of checkable evidence and optional context acquisition. Q's full peer-scoring and optimal-oversight theorems do not by themselves predict P's measured F1.
